Reproducibility Package

This package provides the algorithms, Python implementations, experimental data, and computational results supporting the manuscript:
`Exact Dominance and Budget-Restricted Fleet Reachability in Lagged Facility–Fleet Adaptation`

Package Contents:

`01_Algorithms` : Pseudocode documenting the computational algorithms implemented in the Python modules.

`02_Python` : Python modules for data generation, numerical experiments, results reporting, and associated original verification programs.

`03_Data` : Materialized datasets, experimental instances, and their frozen protocol.

`04_Results/Raw`: Original computational outputs produced by the experimental and validation algorithms.

`04_Results/Tables_XLSX` : Manuscript table represented in XLSX format from the original stored CSV.

`04_Results/Figures_PNG` : Manuscript figure generated from stored computational results.
